# 🎮 NEONCORE – Gamer Sign-up Form

A futuristic, gaming-inspired sign-up form built with **HTML, CSS, and Vanilla JavaScript**.

NEONCORE features a modern dark interface with neon-green accents, real-time form validation, password strength feedback, and a live operator verification system.

## 🚀 Features

- **Futuristic UI:** Dark gaming theme with neon-green accents and custom typography.
- **Callsign Validation:** Ensures the username contains 3–20 characters (letters, numbers, underscores, or hyphens).
- **Email Validation:** Checks email input format in real time.
- **Password Strength Indicator:** Evaluates password strength based on length, numbers, uppercase letters, and special characters.
- **Password Visibility Toggle:** Show or hide passwords using the eye icons.
- **Confirm Password:** Checks whether the confirmation password matches the original password.
- **Terms & Conditions:** Requires users to accept the terms before completing registration.
- **Live Status Tracker:** Displays the validation status of each field.
- **Ready Counter:** Tracks completed requirements out of 5.
- **Operator Verification:** Changes the operator status to "Verified" when all requirements are completed.

## 🛠️ Technologies Used

- **HTML5** – Form structure and semantic elements.
- **CSS3** – Styling, Flexbox, custom properties, and visual effects.
- **JavaScript (Vanilla JS)** – Form validation, DOM manipulation, and interactive functionality.
- **Google Fonts:**
  - Orbitron
